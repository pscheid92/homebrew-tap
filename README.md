# pscheid92/homebrew-tap

Homebrew casks for [pscheid92](https://github.com/pscheid92)'s command-line tools.

```sh
brew install pscheid92/tap/kpg
brew install pscheid92/tap/pqsign
```

| Cask | Description |
|---|---|
| [kpg](https://github.com/pscheid92/kpg) | Command-first CLI for connecting to Kubernetes-hosted Postgres databases |
| [pqsign](https://github.com/pscheid92/pqsign) | Hybrid post-quantum file signing with Ed25519 and ML-DSA-65 |

The kpg cask is generated by GoReleaser when a release is published; edits made
here by hand are overwritten by the next release. The pqsign cask is updated by
hand for each release.
